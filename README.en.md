# Tiny Weekly Review

A manager weekly review generated from structured TinyManager module signals instead of a long manual form.

Typical automatic inputs include completed/open delegations, overdue deadlines, high risks, stale Waiting For items and recorded decisions.

## Alpha

- Deterministic, testable domain generator
- Standalone preview
- TinyManager module package
- Wins / Attention / Next output
- TypeScript declarations, tests and CI

Version: `0.1.0-alpha.1`
